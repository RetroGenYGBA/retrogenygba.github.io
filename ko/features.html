기능과 설정

주요 기능과 성능 설정이 하는 일.

무료와 프리미엄

게임 플레이, 게임 내 저장, 상태 저장, 치트, 컨트롤러, 화면 버튼, 화면 방향은 모두 무료입니다. 다음은 프리미엄 기능입니다.

  • 빨리 감기: 1.5배, 2배, 4배(0.5배와 1배는 무료)
  • 되감기: 되감기 버튼을 누르고 있으면 게임이 뒤로 갑니다
  • 연사: 버튼을 누르고 있으면 고른 속도로 반복해서 누릅니다
  • 필터: LCD, 스캔라인, 색 보정, xBRZ, HQ4x, ScaleFX, FSR 등
  • 메모리 검색: 직접 값을 찾아 치트를 만들기

앱 안에서 일정 시간 무료로 잠금 해제하거나, 한 번 구매해서 계속 쓸 수 있습니다.

화면

  • 필터: 게임 메뉴에서 게임마다 전환합니다.
  • LCD 잔상: 원래 화면의 느린 반응을 재현합니다. 한 프레임 걸러 스프라이트를 깜빡여 반투명처럼 보이게 하는 게임이 제대로 보입니다.
  • 빠른 렌더링: 픽셀 단위가 아니라 스캔라인 한 줄씩 그립니다. 훨씬 빠르고 화면은 똑같습니다. 기본으로 켜져 있습니다.
  • 멀티스레드 렌더링: 에뮬레이션과 렌더링을 CPU 코어 두 개에서 동시에 처리합니다. 빠른 렌더링이 필요합니다.

게임 메뉴: 속도, 렌더러, 성능 스위치를 게임을 나가지 않고 바꿀 수 있습니다.

성능과 배터리

  • CPU 연속 실행: 아무 일도 없을 때 명령 사이의 검사를 건너뜁니다. 더 빠르고 배터리도 덜 쓰며 결과는 똑같습니다. 통신 중에는 자동으로 꺼집니다.
  • 절전: 같은 프레임을 다시 그리지 않는 등으로 아껴서 휴대폰이 덜 뜨거워집니다. 게임마다 설정할 수 있습니다.

이 설정들은 게임을 나가지 않고 게임 메뉴의 화면 항목에서 바꿀 수 있습니다. 화면이나 동작이 이상하면 먼저 이 스위치들을 꺼 보세요.

소리

  • 고품질 오디오: 더 세밀한 리샘플링으로 헤드폰에서 더 깨끗하게 들립니다.
  • 휴대용 기기 스피커 소리: 모노이며, 내장 스피커처럼 저음과 고음을 깎아 원래 소리를 재현합니다.

컨트롤러와 카트리지 기능

  • 게임패드와 키보드 버튼: 무엇이든 다시 지정할 수 있으며, GBA 버튼 하나에 키 여러 개를 지정할 수 있습니다.
  • 카트리지 진동: 진동 카트리지 게임(포켓몬 핀볼 루비&사파이어 등)에서 휴대폰이나 컨트롤러가 진동합니다.
  • 센서 카트리지: 기울기, 자이로, 태양 센서가 있는 게임은 휴대폰의 센서를 씁니다. 다음 항목을 보세요.

센서 카트리지

카트리지에 센서가 들어 있어서 햇빛 아래로 나가거나 기기를 기울이고 비틀어야 하는 게임이 있었습니다. RetroGenY는 이 게임들을 인식해 설정 없이 자동으로 휴대폰의 센서로 바꿔 씁니다. 게임이 시작되면 어떤 센서를 쓰는지, 또는 휴대폰에 필요한 센서가 없는지 알려 줍니다.

  • 햇빛(볼크트 1, 2, 3): 휴대폰의 조도 센서가 카트리지의 태양 센서를 대신합니다. 빛이 밝을수록 게임 속 햇빛이 많아집니다. 밖으로 나가거나 화면 위쪽에 조명을 비추고 태양 게이지가 차는 것을 보세요. 조도 센서는 보통 전면 카메라 옆에 있으니 손가락으로 가리지 마세요. 조도 센서가 없는 휴대폰은 중간 정도의 햇빛을 받습니다.
  • 기울기(요시의 만유인력, 코로코로 퍼즐): 휴대폰의 가속도계를 써서, 원래처럼 휴대폰을 기울여 스테이지를 돌리거나 캐릭터를 굴립니다. 게임이 시작될 때 휴대폰을 든 자세가 수평으로 간주됩니다. 다시 맞추려면 게임을 나갔다가 다시 시작하세요. 세로와 가로 모두 되며 방향은 화면을 따라갑니다.
  • 자이로(빙글빙글 메이드 인 와리오): 휴대폰의 자이로스코프를 씁니다. 핸들처럼 화면 평면에서 휴대폰을 돌리세요.
  • GBC 기울기 카트리지(코로코로 커비 등): 마찬가지로 가속도계로 기울기를 조작하며, 카트리지 세이브도 평소처럼 보관됩니다.

컨트롤러를 연결해도 센서는 휴대폰 자체를 읽으므로, 기울기 게임은 휴대폰을 들고 하는 것이 좋습니다. 앱이 백그라운드로 가면 센서가 멈추고 돌아오면 다시 작동하므로 배터리를 낭비하지 않습니다.

RetroAchievements

설정 › RetroAchievements에서 켜고 retroachievements.org 계정(무료 가입)으로 로그인하세요. 게임을 시작하면 앱이 게임을 인식해 업적 수를 알려 줍니다. 플레이 중에 달성 팝업이 뜨고, 게임 메뉴의 "업적"에서 전체 목록과 진행 상황을 볼 수 있습니다.

  • RetroAchievements는 등록된 게임 버전만 인식하므로(게임 파일의 체크섬을 확인) 한글화 패치나 롬 해킹에는 보통 업적이 없습니다.
  • 켜져 있는 동안에는 공정성을 위해 치트와 메모리 편집이 멈춥니다. 빨리 감기, 되감기, 상태 저장은 계속 쓸 수 있습니다.
  • 오프라인에서 달성한 업적은 저장되었다가 다시 온라인이 되면 전송됩니다.
  • RetroAchievements는 무료입니다.

상태 저장과 되감기

상태 저장 슬롯마다 썸네일이 있고, 불러오기를 되돌릴 수 있습니다. 되감기에는 메모리가 좀 필요하며, 부족하면 켜지 못했다고 알려 줍니다.

상태 저장 메뉴: 새 슬롯, 자동 저장, 이전 슬롯.
