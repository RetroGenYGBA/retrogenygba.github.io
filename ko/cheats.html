치트

내장 치트 데이터베이스는 바로 쓸 수 있습니다. 다른 곳에서 찾은 코드를 붙여 넣거나 직접 써도 됩니다.

내장 치트 데이터베이스

데이터베이스는 1,700개 이상의 게임, 9,000개 이상의 치트를 다룹니다. 게임 중에 치트 패널을 열면 카트리지의 게임 코드로 그 게임의 치트를 찾아 줍니다. 추가를 누르면 적용됩니다.

앱이 영어일 때는 치트 이름이 영어로 표시됩니다.

같은 게임이라도 버전(1.0과 1.1 등)에 따라 주소가 다를 수 있어서 데이터베이스 코드가 모든 버전에서 작동하지는 않습니다. 안 되면 다른 버전용 코드를 써 보거나 직접 찾아보세요.

왼쪽: "데이터베이스"에 이 게임의 치트가 나열됩니다. 추가를 누르세요. 오른쪽: "내 치트", 치트마다 개별 스위치가 있습니다. +를 눌러 코드를 붙여 넣으세요.

치트 붙여 넣기

치트 패널에 코드를 붙여 넣으면 형식이 자동으로 인식되고, 켜면 매 프레임 적용됩니다. 지원 형식:

  • GameShark / Action Replay
  • CodeBreaker
  • 메모리 직접 쓰기(VBA Raw 등)
  • RetroGenY 확장 코드(아래 참고)

주석은 # 또는 !, 줄 묶음은 [섹션] 제목을 쓰세요. 읽을 수 없는 줄은 그냥 무시하지 않고 알려 줍니다.

RetroGenY 확장 코드

자체 치트 형식으로, 포인터를 따라가고 반복하고 조건을 판단하고 버튼에 반응합니다. 그래서 일반 코드가 안 되는 곳에서도 작동합니다. 저장할 때마다 위치가 바뀌는 데이터, 암호화된 돈, 가방 전체. 편집기는 입력하면서 검사하고, 어떤 코드든 쉬운 말로 설명하며, 시작용 템플릿도 있습니다. 확장 코드 자세히 보기.

메모리 도구로 직접 만들기

원하는 치트가 없나요? 떠 있는 창에서 게임 메모리를 검색해 값을 고정하고, 감시 지점으로 새로 저장해도 작동하는 치트를 만드세요. 게임의 동작을 바꾸거나, 모든 무작위 판정을 마음대로 할 수도 있습니다. 메모리 도구 자세히 보기.

통신 중에는

통신 중에는 모든 치트가 멈추고, 게임 자체를 바꾸는 치트는 먼저 원래대로 돌려서 두 게임이 맞춰 진행되게 합니다. 케이블을 뽑으면 다시 작동합니다.

RetroGenY는 게임을 포함하거나 배포하지 않습니다. 게임보이, 게임보이 컬러, 게임보이 어드밴스는 닌텐도의 상표이며, 이 프로젝트는 닌텐도와 관련이 없습니다.RedditDiscordTelegram개인정보 처리방침
