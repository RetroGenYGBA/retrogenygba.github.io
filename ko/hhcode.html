확장 코드

RetroGenY만의 치트 형식입니다. 일반 코드는 한 주소에 값 하나를 쓰지만, 확장 코드는 짧은 프로그램입니다. 포인터를 따라가고, 반복하고, 조건을 판단하고, 게임이 숫자를 숨기는 데 쓰는 계산까지 할 수 있습니다.

일반 코드가 부족한 이유

GameShark, Action Replay, CodeBreaker는 2000년대 초 카트리지를 위해 만들어졌습니다. "여기에 계속 99를 쓰기"는 잘하지만 그게 거의 전부입니다. 많은 게임은 데이터를 한곳에 두지 않습니다.

  • 움직이는 데이터.포켓몬과 많은 RPG는 가방, 파티, 돈을 포인터 뒤에 두고, 주소는 저장할 때마다, 심지어 메뉴를 열 때마다 바뀝니다. 고정 주소 코드는 오늘은 되다가 내일은 조용히 작동을 멈춥니다.
  • 암호화된 값.파이어레드와 리프그린은 돈을 세이브마다 다른 키와 XOR해서 저장합니다. 999999를 바로 쓰면 엉뚱한 숫자가 되므로 먼저 키를 읽어야 합니다.
  • 목록 전체.42칸 가방의 아이템을 전부 99로 하려면 코드 42개가 필요하고, 뭔가 줍는 순간 어긋납니다.
  • 조건."L+R을 누를 때만", "빈 칸에만", "전투 중에만"은 대부분 불가능합니다.

확장 코드는 바로 이런 경우를 위해 만들었습니다.

할 수 있는 것

  • 포인터 따라가기: 게임과 같은 방식으로, 그래서 어떤 세이브에서도 계속 작동합니다.
  • 반복: 가방, 파티, PC 박스를 repeat 42 … end로 처리.
  • 조건 판단: 메모리 비교, 비트 테스트, 빈 칸 건너뛰기, else 추가.
  • 버튼에 반응: 버튼 조합을 누르고 있는 동안만 실행, "L+R로 회복"처럼.
  • 계산: 레지스터 8개로 더하기, 빼기, 곱하기, AND, OR, XOR, 시프트. 게임이 기대하는 방식으로 값을 인코딩하기에 충분합니다.
  • 복사: 다른 곳에서 값 하나나 연속된 칸 전체를.
  • 게임 자체 수정: rom 줄로 값만으로는 안 되는 변경을(1원짜리 상점, 벽 통과).
  • 선택지 제공.option 줄은 값을 치트 목록의 드롭다운으로 바꿔, 플레이어가 코드를 건드리지 않고 "×2 / ×5 / ×10"을 고를 수 있습니다.

왼쪽: 편집기가 입력하는 동안 코드를 검사합니다. 오른쪽: 선택지가 있는 코드는 목록에 바로 드롭다운이 생깁니다.

실제 예

파이어레드(영문판 v1.0)의 돈 999999. 돈은 포인터 뒤에 있고 세이브의 키로 암호화되어 있어 일반 코드로는 다룰 수 없습니다.

hhcode 1
r0 = [0x03005008]        # 세이브 블록 1: 돈과 아이템
r1 = [0x0300500C]        # 세이브 블록 2: 키가 있음
r2 = [r1 + 0xF20]        # 키 읽기
r2 = r2 ^ 999999         # 키로 999999 인코딩
[r0 + 0x290].32 = r2     # 돈 쓰기

가방의 모든 아이템을 99로, 빈 칸은 건너뛰기:

hhcode 1
r0 = [0x03005008]
r1 = [0x0300500C]
r2 = [r1 + 0xF20]
r2 = r2 ^ 99             # 개수도 암호화됨
r0 = r0 + 0x310          # 가방: 42칸
repeat 42
  if [r0].16 != 0        # 빈 칸 건너뛰기
    [r0 + 2].16 = r2
  end
  r0 = r0 + 4            # 다음 칸
end

L+R을 누르고 있으면 HP 회복(주소는 예시):

hhcode 1
if button L + R
  [0x02024330].16 = 999
end

플레이어가 치트 목록에서 바꿀 수 있는 선택지:

hhcode 1
option Multiplier = 2 { 2 ×2; 5 ×5; 10 ×10 }
[0x02001000].8 = $Multiplier

사용 방법

  1. 게임 중에 치트 패널을 열고 "내 치트"로 가서 +를 누르세요.
  2. 이름을 붙이고 코드를 입력하거나 붙여 넣으세요. 첫 줄은 hhcode(또는 hhcode 1)여야 합니다.
  3. 편집기가 입력하는 동안 모든 줄을 검사합니다. 실수는 줄 번호와 함께 표시되고, 올바른 코드에는 "문법 정상"이 표시됩니다.
  4. 누군가 보내 준 코드처럼 무엇을 하는지 모르겠나요? "이 코드 설명 보기"를 누르면 쉬운 말로 읽어 줍니다.
  5. 처음부터 쓰기 싫다면 "확장 코드 템플릿"을 여세요. 값 고정, 포인터 체인, 연속된 칸, 값 복사, 테이블 순회, 조건부 쓰기, else 분기, 버튼 트리거, 비트 스위치 등. 하나를 골라 주소와 값만 바꾸면 됩니다.
  6. 추가를 누르고 켜세요. 다른 치트처럼 매 프레임 실행됩니다.

직접 쓸 필요가 없는 경우도 많습니다. 메모리 도구가 값을 찾고 포인터 기반 확장 코드를 대신 써 줍니다.

안전하게 설계

  • 게임을 멈추게 하지 않습니다.한 번 실행에 최대 200,000개 명령까지만 실행하므로 잘못 쓴 반복문은 그냥 멈춥니다.
  • 크기는 너그럽게.값이 쓴 크기에 들어가지 않으면 몰래 잘라내지 않고 넓힌 뒤 알려 줍니다.
  • 흔한 실수를 경고합니다.예를 들어 다른 형식의 오프셋처럼 보이는 주소.
  • 값은 값.10진수와 16진수는 같은 뜻이며, 쓰는 것은 숫자이지 바이트 순서가 아닙니다.

데이터베이스 전체가 이 형식

내장 데이터베이스의 1,700개 이상 게임, 9,000개 이상의 치트가 확장 코드로 변환되었고, 하나하나 원래 코드와 바이트 단위로 대조했습니다. 일부 게임에는 예전 형식으로는 표현할 수 없었던 직접 작성한 확장 코드도 추가했습니다. 파이어레드의 암호화된 돈과 가방 전체 등. GameShark, Action Replay, CodeBreaker 코드도 예전과 똑같이 작동합니다.

RetroGenY는 게임을 포함하거나 배포하지 않습니다. 게임보이, 게임보이 컬러, 게임보이 어드밴스는 닌텐도의 상표이며, 이 프로젝트는 닌텐도와 관련이 없습니다.RedditDiscordTelegram개인정보 처리방침
