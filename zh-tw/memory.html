記憶體工具

找到遊戲裡的任何數字、鎖住它，再變成任何存檔都有效的金手指，全程不用離開遊戲。還能更進一步：改變遊戲的行為，或左右它的運氣。

用來做什麼

金手指資料庫涵蓋很多，但不是全部：沒那麼有名的遊戲、漢化版、改版，或者你只在意的那一個數值。記憶體工具讓你自己做出那條金手指。大多數模擬器做到「搜尋並鎖定位址」就停了，RetroGenY 還會繼續：

  • 在遊戲上方的浮動視窗裡執行。移動、縮放它，讓你要找的數字一直看得到，邊搜邊玩。
  • 換存檔也有效的金手指。監看點會顯示遊戲自己從哪裡找到這個數值，金手指就照同樣的路徑寫成擴充碼。
  • 改變遊戲的行為，而不只是數字：讓計數器永遠不減少、略過某個檢查，全都從碰過這個數值的指令列表裡做。
  • 控制隨機性。找到隨機數種子、預知接下來的結果，或讓每次判定都是最好的結果。

記憶體工具視窗浮在遊戲上方。拖曳標題列移動，拖曳角落調整大小。

開啟方式

  1. 在遊戲裡打開遊戲選單，在「工具」下開啟記憶體搜尋。
  2. 遊戲畫面下方會出現記憶體搜尋鍵。點它打開視窗，點 ✕ 關閉。搜尋進度會保留。

記憶體搜尋是進階功能。用它做出的金手指和其他金手指一樣會儲存，之後照樣有效。

找一個數值

假設你有 1,250 金幣，想要 999,999。

  1. 選寬度。金錢通常是 16 或 32 位元；生命數這類小計數器常是 8 位元。不確定就先試 32 位元。
  2. 輸入你看到的數值（1250），條件保持「=」，點開始搜尋。
  3. 在遊戲裡讓數值變化：買點東西、撿點錢。
  4. 輸入新數值，點繼續篩選。重複到只剩幾個位址。
  5. 在結果上點金手指，「鎖定為」設成 999999，點儲存到金手指。

不知道數字？血條、計時器和隱藏能力值都不顯示數字。改用條件搜尋：被打一下後用「已減少」篩選，補血後用「已增加」，站著不動用「未改變」。另外還有不等於、大於和小於。

一直有效的金手指

單純鎖住位址，遊戲一搬動資料就會失效，而很多遊戲每次存檔都會搬。記憶體工具能解決這個問題：

  1. 在找到的結果上點監看。
  2. 在遊戲裡讓數值變化一次。
  3. 模擬器會停在寫入它的那條指令，並記錄遊戲是怎麼找到那個位址的。
  4. 再點一次金手指。這次寫出的代碼會跟著遊戲自己的指標，並且註明：「透過遊戲自己用的指標定位，換存檔後依然有效。」

左：從監看點產生的金手指，是跟隨指標的擴充碼。右：運氣讓每次隨機判定都是最好（或最差）的結果。

改變遊戲的行為

有時候你要的不是鎖住數值，而是讓錢不會減少但還能賺，或者讓某個檢查一定通過。「監看」分頁會列出每一條寫入你這個位址的指令，並附上次數：

  1. 點清空計數，然後在遊戲裡做那件事（買東西、受傷）。「記錄寫入但不暫停遊戲」可以讓遊戲照常順暢。
  2. 回來找出次數增加的那一條。
  3. 點修改並選擇：替換成 NOP、加減互換、改常數、永遠跳轉、永不跳轉、寫死暫存器的值，或自己寫一行組合語言。
  4. 它會變成一條普通的金手指，名字由你取。

遊戲程式常被共用：扣你錢的那段程式也可能負責發獎勵。可能有這種情況時 App 會提醒你；用中斷點確認那條指令只在你預期的時候執行。關掉指令類金手指要重新開啟遊戲才會生效。

隨機與運氣

大多數遊戲用一行算式擲骰子，存放種子的那 4 個位元組是記憶體裡唯一每次變化都符合那條式子的資料。「種子」分頁會幫你找到它們：

  • 運氣：「最好」或「最差」會把遊戲的每次擲骰壓到最小或最大值。爆擊、稀有掉寶、捕捉都算。如果「最好」反而什麼都失敗，表示這個遊戲是數字越大越好，改用「最差」。它對敵人也有效，用完記得關掉。
  • 進階：在遊戲閒置的地方掃描種子、看它接下來會產生的值，並鎖定種子。

給好奇的你

  • 記憶體：任何位址的十六進位檢視，可以直接從搜尋結果打開。
  • 中斷點：在某條指令執行時停下，再一次一條指令單步執行並查看暫存器。
  • 關掉視窗後監看點仍然有效。觸發時視窗會自己打開。

有什麼不同

  • 搜尋、鎖定、儲存都不用離開遊戲或切換 App。
  • 自動產生指標金手指，下次存檔也不會失效。
  • 指令類金手指直接來自真正寫入的指令列表，不需要反組譯器。
  • 運氣控制適用於各種遊戲，因為它針對的是遊戲擲骰子的方式，而不是某個遊戲的位址。
  • 你做出來的都是普通金手指：取個名字，像其他金手指一樣開關。
