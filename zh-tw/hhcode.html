擴充碼

RetroGenY 自己的金手指格式。一般代碼只是把一個值寫到一個位址；擴充碼是一段小程式：能跟隨指標、跑迴圈、判斷條件，還能做遊戲用來藏數字的那些算術。

一般代碼哪裡不夠

GameShark、Action Replay 和 CodeBreaker 是為 2000 年代初的卡匣設計的。它們很擅長「一直把 99 寫到這裡」，也就僅止於此。很多遊戲的資料不會固定在一個地方：

  • 會移動的資料。寶可夢和許多 RPG 把背包、隊伍和金錢放在指標後面，位址每次存檔、甚至每次打開選單都會變。固定位址的代碼今天有效，明天就默默失效。
  • 加密的數值。火紅和葉綠把金錢和一把每個存檔都不同的鑰匙做 XOR。直接寫 999999 只會得到一個亂數；必須先讀出鑰匙。
  • 整個列表。要把 42 格背包裡每樣道具都改成 99，需要 42 條代碼，而且一撿東西就全亂了。
  • 條件。「只在按住 L+R 時」「只對空格子」「只在戰鬥中」，大多做不到。

擴充碼就是為這些情況做的。

能做什麼

  • 跟隨指標，方式和遊戲自己一樣，所以代碼在任何存檔都有效。
  • 跑迴圈：走訪背包、隊伍或電腦箱子，用 repeat 42 … end。
  • 判斷條件：比較記憶體、測試位元、略過空格子，還能加 else。
  • 回應按鍵：只在按住某個按鍵組合時執行，像是「按 L+R 回血」。
  • 計算：八個暫存器，加、減、乘、AND、OR、XOR 和位移，足以把數值編碼成遊戲要的樣子。
  • 複製：從別處複製一個值或一整排格子。
  • 修改遊戲本身：用 rom 行做到光改數值做不到的事（商店只收 1 元、穿牆）。
  • 提供選項。option 行會把數值變成金手指列表裡的下拉選單，玩家選「×2 / ×5 / ×10」就好，不用碰代碼。

左：編輯器邊輸入邊檢查代碼。右：有選項的代碼直接在列表裡出現下拉選單。

實際例子

火紅（英文版 v1.0）金錢 999999。金錢放在指標後面，還用存檔的鑰匙加密，一般代碼都處理不了：

hhcode 1
r0 = [0x03005008]        # 存檔區塊 1：金錢和道具在這裡
r1 = [0x0300500C]        # 存檔區塊 2：鑰匙在這裡
r2 = [r1 + 0xF20]        # 讀出鑰匙
r2 = r2 ^ 999999         # 用它加密 999999
[r0 + 0x290].32 = r2     # 寫入金錢

背包裡每樣道具都改成 99，空格子略過：

hhcode 1
r0 = [0x03005008]
r1 = [0x0300500C]
r2 = [r1 + 0xF20]
r2 = r2 ^ 99             # 數量也是加密的
r0 = r0 + 0x310          # 背包：42 格
repeat 42
  if [r0].16 != 0        # 空格子略過
    [r0 + 2].16 = r2
  end
  r0 = r0 + 4            # 下一格
end

按住 L+R 補滿 HP（位址僅為示範）：

hhcode 1
if button L + R
  [0x02024330].16 = 999
end

玩家可以在金手指列表裡切換的選項：

hhcode 1
option Multiplier = 2 { 2 ×2; 5 ×5; 10 ×10 }
[0x02001000].8 = $Multiplier

怎麼使用

  1. 在遊戲裡打開金手指面板，進入「我的金手指」，點 +。
  2. 取個名字，再輸入或貼上代碼。第一行必須是 hhcode（或 hhcode 1）。
  3. 編輯器會邊輸入邊檢查每一行。有錯會標出行號；正確的代碼會顯示「語法正確」。
  4. 不確定一條代碼在做什麼，例如別人傳給你的？點 「查看這段代碼的說明」，它會用白話唸給你聽。
  5. 不想從零開始？打開 「擴充碼範本」：鎖定數值、指標鏈、連續格子、複製數值、走訪表格、條件寫入、否則分支、按鍵觸發、位元開關等。選一個，改掉位址和數值就好。
  6. 點「新增」並打開開關。和所有金手指一樣，每個畫格執行一次。

很多時候根本不用自己寫：記憶體工具能找到數值，並幫你寫出跟隨指標的擴充碼。

語法一覽

代碼作用
[addr] = v寫入（預設 32 位元）
[addr].16 = v指定寬度寫入：.8 / .16 / .32
[addr] = 40,42,0F寫入一串位元組
[addr].16 = 99 repeat 30 step 4寫入 30 格，每格相隔 4 位元組
[dst].16 = [src]複製一個值
[addr].16 += 5讀出、修改、寫回：+= -= &= |=
r0 = [0x03005008]把記憶體讀進暫存器（指標鏈的開頭）
r0 = [r0 + 0x14]沿指標再跳一層
[r0 + 4].8 = v相對暫存器寫入

if [addr] == v … end條件：== != < > <= >=，無號 <u >u，位元測試 & 和 !&

… else … end否則

完整的參考和所有規則都在 App 裡：金手指面板 › 「說明」 › RetroGenY 擴充碼。

設計得很安全

  • 不會讓遊戲卡死。每次執行最多 200,000 條指令，寫錯的迴圈只會停下來。
  • 寬度很寬容。數值放不進你寫的寬度時，會自動加寬並提醒你，而不是默默截斷。
  • 會提醒可能的錯誤，例如看起來像其他格式偏移量的位址。
  • 數值就是數值。十進位和十六進位意思一樣，你寫的是數字，不是位元組順序。

整個資料庫都用它

內建資料庫裡 1700 多款遊戲的 9000 多條金手指都已轉成擴充碼，每一條都和原碼逐位元組核對過。有些遊戲還加了手寫的擴充碼，是舊格式寫不出來的，例如火紅的加密金錢和整個背包。GameShark、Action Replay 和 CodeBreaker 代碼也照舊可用。
