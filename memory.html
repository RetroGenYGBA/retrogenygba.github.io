Memory tools

Find any number in a game, lock it, and turn it into a cheat that keeps working in every save, without leaving the game. Then go further: change how the game behaves, or bend its luck.

What it's for

The cheat library covers a lot, but not everything: a less famous game, a translation patch, a ROM hack, or just the one value you care about. Memory tools let you make that cheat yourself. Most emulators stop at "search and lock an address". RetroGenY keeps going:

  • It runs in a floating window over the game. Move it and resize it so the number you're hunting stays visible, and keep playing while you search.
  • Cheats that survive a new save. A watchpoint shows where the game itself finds the value, and the cheat is written to follow the same path, as an extended code.
  • Change the game's behaviour, not just its numbers: make a counter never go down, skip a check, all from a list of the instructions that touched your value.
  • Control randomness. Find the random-number seed, see what's coming, or force every roll to the best result.

The memory tools window floats over the game. Drag the title bar to move it, the corner to resize it.

Turning it on

  1. In a game, open the game menu and, under Tools, switch on Memory search.
  2. A memory search key appears under the game screen. Tap it to open the window; tap ✕ to close it. Your search stays where you left it.

Memory search is a premium feature: watch one ad to use it for 2 hours. Cheats you make with it are saved like any other and keep working afterwards.

Finding a value

Say you have 1,250 gold and want 999,999.

  1. Pick a width. Money is usually 16- or 32-bit; small counters like lives are often 8-bit. If unsure, try 32-bit first.
  2. Type the value you see (1250), keep the condition on "=", and tap Search.
  3. Change the value in the game: buy something, pick some up.
  4. Type the new value and tap Refine. Repeat until only a few addresses remain.
  5. Tap Cheat on a result, set "Lock to" to 999999 and tap Save to cheats.

Don't know the number? HP bars, timers and hidden stats show no digits. Search with a condition instead: take a hit and refine with "decreased", heal and refine with "increased", stand still and refine with "unchanged". Also available: not equal, greater than and less than.

Cheats that keep working

A plain locked address breaks when the game moves its data, which many games do on every save. Memory tools fix that:

  1. Tap Watch on the result you found.
  2. Make the value change once in the game.
  3. The emulator stops at the instruction that wrote it and records how the game got to that address.
  4. Now tap Cheat again. The code it writes follows the game's own pointer, and says so: "Resolved through the pointer the game itself uses, so it remains valid in other saves."

Left: a cheat generated from a watchpoint, as an extended code that follows the pointer. Right: Luck forces every random roll to the best (or worst) result.

Changing what the game does

Sometimes locking a value isn't what you want. You want money to stop going down while still letting you earn it, or a check to always pass. The Watches tab lists every instruction that wrote your address, with a count:

  1. Tap Clear counts, then do the thing in the game (buy something, take damage). "Record without pausing the game" keeps play smooth.
  2. Come back and find the entry whose count went up.
  3. Tap Modify and choose: replace with NOP, swap add and subtract, edit a constant, always jump, never jump, fix a register's value, or type one line of assembly.
  4. It becomes a cheat like any other, with a name you choose.

Game code is often shared: the routine that takes your money may also pay rewards. The app warns you when this is likely; use a breakpoint to check the instruction only runs when you expect. Turning off an instruction cheat takes effect after reopening the game.

Randomness and luck

Most games roll their dice with one line of arithmetic, and the four bytes holding its seed are the only data in memory whose every change fits that formula. The Seed tab finds them for you:

  • Luck: Best or Worst forces every roll in the game to its lowest or highest value. Critical hits, rare drops, catches. If Best makes everything fail, the game counts high rolls as good; switch to Worst. It affects enemies too, so turn it off when you're done.
  • Advanced: scan for the seed somewhere the game is idle, see the next values it will produce, and lock the seed.

For the curious

  • Memory: a hex view of any address, opened straight from a search result.
  • Breakpoints: stop when a given instruction runs, then step one instruction at a time and read the registers.
  • Watchpoints keep working while the window is closed. When one fires, the window opens by itself.

Why it's different

  • Search, lock and save without leaving the game or switching apps.
  • Pointer-based cheats generated for you, so they don't break with the next save.
  • Instruction cheats from a list of real writers, no disassembler needed.
  • Luck control that works across games, because it targets how games roll dice, not one game's addresses.
  • Everything you make is an ordinary cheat: name it and switch it on and off like any other.
