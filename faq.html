Didn't find your answer here? Post on our Reddit, or ask in our Discord or Telegram group. Players there also look for people to link with.

Link play

"The other phone is running a different app version"

The two phones have different versions of RetroGenY, and their link protocols don't match. Update both to the latest version and connect again.

The message as it appears. "Export link log" (highlighted) is always at the bottom of the link panel.

I can't find the room

  • Make sure both phones are on the same Wi-Fi. Some public networks (hotels, schools) block devices from reaching each other; use a hotspot on one phone instead.
  • In "Join room", type the address shown on the host's screen.
  • Or connect over Bluetooth or a cable.

Room not listed? Type the address shown on the host's screen here.

The game stutters once linked

A normal link is sensitive to network delay. Have the host turn on MirrorLink, and use the fastest phone as the host. Moving closer to the router helps too.

MirrorLink keeps saying it's receiving game data

Sometimes MirrorLink needs to get some data ready before the game starts. It's slow over Bluetooth and much faster over Wi-Fi. With several players, they take turns.

How do I report a problem?

Tap "Export link log" at the bottom of the link panel and email the file to retrogeny2026@gmail.com with a description of what happened.

Games and saves

My game list is empty

Check that you chose the folder that contains your .gba, .gb or .gbc files. Unzip archives first.

How do I move my saves to a new phone?

In-game saves are the .sav files next to each game. Copy them with the games into the games folder on the new phone.

A game won't start or looks wrong

Turn off Fast rendering, Multithreaded rendering and Continuous CPU execution first. A few games need the official BIOS, which you can import in Settings › GBA BIOS. If it still fails, tell us the game name and version.

Cheats

A cheat does nothing

Different versions of the same game can use different addresses. Check your cartridge version and try a code for another version, or find one with memory search. Cheats are paused while linked.

The game misbehaves after a cheat

Turn the cheat off and load a save state from before. Cheats that change encrypted data (editing a Pokémon's stats directly, for example) can make the save fail its own checks, so make a save state before trying them.
