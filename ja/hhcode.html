拡張コード

RetroGenY 独自のチート形式です。普通のコードは 1 つのアドレスに 1 つの値を書くだけですが、拡張コードは小さなプログラムです。ポインタをたどり、ループし、条件を判定し、ゲームが数値を隠すための計算もできます。

普通のコードで足りない理由

GameShark、Action Replay、CodeBreaker は 2000 年代初めのカートリッジ向けに作られました。「ここにずっと 99 を書く」は得意ですが、それくらいです。多くのゲームはデータを 1 か所に置いていません。

  • 動くデータ。ポケモンや多くの RPG はバッグ、手持ち、お金をポインタの先に置いていて、アドレスはセーブのたびに、ときにはメニューを開くたびに変わります。固定アドレスのコードは今日は効いても、明日には黙って効かなくなります。
  • 暗号化された値。ファイアレッドとリーフグリーンは、お金をセーブごとに異なる鍵で XOR して保存しています。999999 を直接書いてもでたらめな数になるので、まず鍵を読む必要があります。
  • リストまるごと。42 スロットのバッグのアイテムをすべて 99 にするには 42 本のコードが必要で、何か拾った瞬間にずれてしまいます。
  • 条件。「L+R を押しているときだけ」「空きスロットだけ」「戦闘中だけ」は、ほとんど実現できません。

拡張コードは、まさにこうしたケースのために作りました。

できること

  • ポインタをたどる：ゲームと同じ方法で。だからどのセーブデータでも効きます。
  • ループ：バッグ、手持ち、パソコンのボックスを repeat 42 … end で処理。
  • 条件を判定：メモリの比較、ビットのテスト、空きスロットの読み飛ばし、else も。
  • ボタンに反応：ボタンの組み合わせを押している間だけ実行。「L+R で回復」のように。
  • 計算：8 つのレジスタで加算、減算、乗算、AND、OR、XOR、シフト。ゲームが期待する形に値を暗号化するには十分です。
  • コピー：別の場所から値を 1 つ、または連続するスロットをまとめて。
  • ゲーム自体を書き換える：rom 行で、値だけではできない変更を（何でも 1 円のショップ、壁抜けなど）。
  • 選択肢を用意。option 行で値をチート一覧のドロップダウンにでき、プレイヤーはコードに触れずに「×2 / ×5 / ×10」を選べます。

左：エディターは入力しながらコードをチェックします。右：選択肢のあるコードは、一覧にそのままドロップダウンが出ます。

実例

ファイアレッド（英語版 v1.0）でお金 999999。お金はポインタの先にあり、セーブの鍵で暗号化されているので、普通のコードでは扱えません。

hhcode 1
r0 = [0x03005008]        # セーブ領域 1：お金とアイテム
r1 = [0x0300500C]        # セーブ領域 2：鍵がある
r2 = [r1 + 0xF20]        # 鍵を読む
r2 = r2 ^ 999999         # 鍵で 999999 を暗号化
[r0 + 0x290].32 = r2     # お金を書き込む

バッグのアイテムをすべて 99 に（空きスロットは飛ばす）：

hhcode 1
r0 = [0x03005008]
r1 = [0x0300500C]
r2 = [r1 + 0xF20]
r2 = r2 ^ 99             # 個数も暗号化されている
r0 = r0 + 0x310          # バッグ：42 スロット
repeat 42
  if [r0].16 != 0        # 空きスロットは飛ばす
    [r0 + 2].16 = r2
  end
  r0 = r0 + 4            # 次のスロット
end

L+R を押している間 HP を回復（アドレスは説明用）：

hhcode 1
if button L + R
  [0x02024330].16 = 999
end

プレイヤーがチート一覧で変えられる選択肢：

hhcode 1
option Multiplier = 2 { 2 ×2; 5 ×5; 10 ×10 }
[0x02001000].8 = $Multiplier

使い方

  1. ゲーム中にチートパネルを開き、「マイチート」で + をタップします。
  2. 名前を付けて、コードを入力または貼り付けます。1 行目は hhcode（または hhcode 1）にしてください。
  3. エディターは入力しながら各行をチェックします。間違いは行番号付きで表示され、正しいコードには「構文 OK」と出ます。
  4. 人からもらったコードなど、何をするのかわからない？ 「このコードの説明」をタップすると、わかりやすい言葉で読み上げてくれます。
  5. 一から書きたくない？ 「拡張コードのテンプレート」を開きましょう。値を固定、ポインタチェーン、連続したスロット、値をコピー、テーブルを走査、条件付き書き込み、else 分岐、ボタントリガー、ビットスイッチなど。選んでアドレスと値を変えるだけです。
  6. 「追加」をタップしてオンにします。ほかのチートと同じく毎フレーム実行されます。

多くの場合、自分で書く必要すらありません。メモリツールが値を見つけ、ポインタ型の拡張コードを書いてくれます。

すべてのルールを含む完全なリファレンスはアプリにあります：チートパネル › 「解説」 › RetroGenY 拡張コード。

安全設計

  • ゲームを固まらせません。1 回の実行は 200,000 命令までなので、書き間違えたループも止まるだけです。
  • 幅は柔軟。書いた幅に値が収まらない場合は、黙って切り捨てずに幅を広げてお知らせします。
  • よくある間違いを警告します。たとえば、ほかの形式のオフセットに見えるアドレスなど。
  • 値は値。10 進も 16 進も同じ意味で、書くのは数値そのもの。バイト順ではありません。

データベースもすべてこの形式

内蔵データベースの 1,700 以上のゲーム、9,000 以上のチートは拡張コードに変換済みで、1 本ずつ元のコードとバイト単位で照合しました。一部のゲームには、昔の形式では書けなかった手書きの拡張コードも加えています。ファイアレッドの暗号化されたお金やバッグまるごとなど。GameShark、Action Replay、CodeBreaker のコードもこれまでどおり使えます。
