Cheats

Die eingebaute Cheat-Bibliothek funktioniert sofort. Du kannst auch woanders gefundene Codes einfügen oder eigene schreiben.

Eingebaute Cheat-Bibliothek

Die Bibliothek umfasst über 1.700 Spiele mit über 9.000 Cheats. Öffne im Spiel das Cheat-Fenster, und die App findet die Cheats dieses Spiels anhand des Spielcodes auf dem Modul. Tippe bei einem auf Hinzufügen, und er wirkt.

Ist die App auf Englisch eingestellt, werden die Cheat-Namen auf Englisch angezeigt.

Verschiedene Versionen desselben Spiels (etwa 1.0 und 1.1) nutzen manchmal andere Adressen, daher funktioniert ein Bibliotheks-Code nicht unbedingt in jeder Version. Klappt einer nicht, probiere einen Code für eine andere Version oder suche selbst.

Links: „Datenbank“ listet die Cheats für dieses Spiel; tippe auf Hinzufügen. Rechts: „Meine Cheats“, wo jeder Cheat seinen eigenen Schalter hat. Tippe auf +, um einen Code einzufügen.

Cheats einfügen

Füge einen Code ins Cheat-Fenster ein. Das Format wird automatisch erkannt, und einmal aktiviert wird der Code in jedem Frame angewendet. Unterstützt:

  • GameShark / Action Replay
  • CodeBreaker
  • Direkte Speicherschreibvorgänge (VBA Raw und ähnliche)
  • Erweiterte RetroGenY-Codes (siehe unten)

Verwende # oder ! für Kommentare und [Abschnitt]-Überschriften zum Gruppieren. Zeilen, die die App nicht lesen kann, werden gemeldet statt stillschweigend ignoriert.

Erweiterte RetroGenY-Codes

Unser eigenes Cheat-Format folgt Zeigern, nutzt Schleifen, prüft Bedingungen und reagiert auf Tasten, daher funktioniert es dort, wo normale Codes versagen: Daten, die mit jedem Spielstand wandern, verschlüsseltes Geld, ganze Beutel. Der Editor prüft beim Tippen, erklärt jeden Code in Klartext und bietet Vorlagen zum Starten. Alles über erweiterte Codes.

Eigene mit den Speicherwerkzeugen bauen

Den gewünschten Cheat nicht gefunden? Durchsuche den Spielspeicher in einem schwebenden Fenster, sperre den Wert und lass einen Beobachtungspunkt daraus einen Cheat machen, der einen neuen Spielstand übersteht. Du kannst sogar ändern, was das Spiel tut, oder jeden Zufallswurf zu deinen Gunsten ausfallen lassen. Alles über die Speicherwerkzeuge.

Während der Verbindung

Alle Cheats pausieren, solange du verbunden bist, und Cheats, die das Spiel patchen, werden vorher rückgängig gemacht, damit beide Spiele synchron bleiben. Nach dem Abziehen sind sie wieder da.
