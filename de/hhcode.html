Erweiterte Codes

Das eigene Cheat-Format von RetroGenY. Ein normaler Code schreibt einen Wert an eine Adresse. Ein erweiterter Code ist ein kurzes Programm: Er kann Zeigern folgen, Schleifen ausführen, Bedingungen prüfen und die Rechnungen nachvollziehen, mit denen ein Spiel seine Zahlen versteckt.

Warum normale Codes nicht reichen

GameShark, Action Replay und CodeBreaker wurden für Module der frühen 2000er entwickelt. Sie können gut „schreib hier immer 99“, und das war's im Grunde. Viele Spiele halten ihre Daten nicht an einer Stelle:

  • Daten, die wandern. Pokémon und viele RPGs legen Beutel, Team und Geld hinter einen Zeiger, und die Adresse ändert sich mit jedem Speichern oder sogar bei jedem Öffnen eines Menüs. Ein Code mit fester Adresse funktioniert heute und morgen stillschweigend nicht mehr.
  • Verschlüsselte Werte. Feuerrot und Blattgrün speichern dein Geld per XOR mit einem Schlüssel, der je Spielstand anders ist. Schreibst du direkt 999999, bekommst du eine Zufallszahl; erst muss der Schlüssel gelesen werden.
  • Ganze Listen. Jedes Item in einem Beutel mit 42 Plätzen auf 99 zu setzen braucht 42 einzelne Codes, und die verrutschen, sobald du etwas aufhebst.
  • Bedingungen. „Nur solange ich L+R halte“, „nur bei leeren Plätzen“, „nur im Kampf“ sind meist unerreichbar.

Erweiterte Codes wurden genau für diese Fälle gemacht.

Was sie können

  • Zeigern folgen wie das Spiel selbst, damit ein Code in jedem Spielstand weiter funktioniert.
  • Schleifen über einen Beutel, ein Team oder eine PC-Box, mit repeat 42 … end.
  • Bedingungen prüfen: Speicher vergleichen, Bits testen, leere Plätze überspringen, und ein else ergänzen.
  • Auf Tasten reagieren: nur laufen, solange eine Tastenkombination gehalten wird, für „L+R zum Heilen“.
  • Rechnen mit acht Registern: Addieren, Subtrahieren, Multiplizieren, AND, OR, XOR und Verschiebungen, genug, um einen Wert so zu kodieren, wie das Spiel ihn erwartet.
  • Kopieren eines Wertes oder einer ganzen Reihe von Plätzen von woanders.
  • Das Spiel patchen mit rom-Zeilen, für Änderungen, die mit Werten allein nicht gehen (ein Laden, der 1 verlangt, durch Wände gehen).
  • Auswahl anbieten. Eine option-Zeile macht aus einem Wert ein Dropdown in der Cheat-Liste, sodass Spieler „×2 / ×5 / ×10“ wählen, ohne den Code anzufassen.

Links: Der Editor prüft den Code beim Tippen. Rechts: Codes mit Optionen bekommen direkt in der Liste ein Dropdown.

Ein echtes Beispiel

Geld 999999 in Feuerrot (englische v1.0). Das Geld liegt hinter einem Zeiger und ist mit dem Schlüssel des Spielstands verschlüsselt, was kein normaler Code bewältigt:

hhcode 1
r0 = [0x03005008]        # Block 1: Geld und Items
r1 = [0x0300500C]        # Block 2: hier liegt der Schlüssel
r2 = [r1 + 0xF20]        # Schlüssel lesen
r2 = r2 ^ 999999         # 999999 damit kodieren
[r0 + 0x290].32 = r2     # Geld schreiben

Jedes Item im Beutel auf 99, leere Plätze überspringen:

hhcode 1
r0 = [0x03005008]
r1 = [0x0300500C]
r2 = [r1 + 0xF20]
r2 = r2 ^ 99             # auch Anzahlen sind verschlüsselt
r0 = r0 + 0x310          # der Beutel: 42 Plätze
repeat 42
  if [r0].16 != 0        # leere Plätze überspringen
    [r0 + 2].16 = r2
  end
  r0 = r0 + 4            # nächster Platz
end

L+R halten, um KP aufzufüllen (Adresse nur als Beispiel):

hhcode 1
if button L + R
  [0x02024330].16 = 999
end

Eine Auswahl, die der Spieler in der Cheat-Liste ändern kann:

hhcode 1
option Multiplier = 2 { 2 ×2; 5 ×5; 10 ×10 }
[0x02001000].8 = $Multiplier

So benutzt du sie

  1. Öffne im Spiel das Cheat-Fenster und geh zu „Meine Cheats“. Tippe auf +.
  2. Gib einen Namen ein und tippe oder füge den Code ein. Die erste Zeile muss hhcode (oder hhcode 1) sein.
  3. Der Editor prüft jede Zeile beim Tippen. Ein Fehler wird mit Zeilennummer angezeigt; ein gültiger Code meldet „Syntax gültig“.
  4. Unsicher, was ein Code macht, etwa einer, den dir jemand geschickt hat? Tippe auf „Diesen Code erklären“, und er wird dir in Klartext vorgelesen.
  5. Keine Lust, bei null anzufangen? Öffne „Vorlagen für erweiterte Codes“: Wert sperren, Zeigerkette, aufeinanderfolgende Plätze, Wert kopieren, Tabelle durchlaufen, bedingtes Schreiben, Else-Zweig, Tasten-Auslöser, Bitschalter und mehr. Wähle eine und ändere Adresse und Wert.
  6. Tippe auf Hinzufügen und schalte ihn ein. Wie jeder Cheat läuft er in jedem Frame.

Oft musst du gar keinen schreiben: Die Speicherwerkzeuge finden einen Wert und schreiben dir einen zeigerbasierten erweiterten Code.

Die vollständige Referenz mit allen Regeln steht in der App: Cheat-Fenster › „Anleitung“ › Erweiterte RetroGenY-Codes.

Auf Sicherheit gebaut

  • Sie können das Spiel nicht einfrieren. Jeder Durchlauf ist auf 200.000 Befehle begrenzt, eine falsch geschriebene Schleife hält also einfach an.
  • Breiten sind nachsichtig. Passt ein Wert nicht in die angegebene Breite, wird sie erweitert und du bekommst einen Hinweis, statt dass er still abgeschnitten wird.
  • Sie warnen vor wahrscheinlichen Fehlern, etwa einer Adresse, die wie ein Offset aus einem anderen Format aussieht.
  • Werte sind Werte. Dezimal und hexadezimal bedeuten dasselbe, und du schreibst die Zahl, nicht ihre Bytereihenfolge.

Die ganze Bibliothek spricht sie

Die über 9.000 Cheats der eingebauten Bibliothek für über 1.700 Spiele wurden in erweiterte Codes umgewandelt, und jeder wurde Byte für Byte mit dem Original abgeglichen. Einige Spiele haben handgeschriebene erweiterte Codes bekommen, die die alten Formate nicht ausdrücken konnten, etwa verschlüsseltes Geld und volle Beutel in Feuerrot. GameShark-, Action-Replay- und CodeBreaker-Codes funktionieren weiterhin genau wie vorher.
