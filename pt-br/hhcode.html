Códigos estendidos

O formato de cheats próprio do RetroGenY. Um código comum escreve um valor num endereço. Um código estendido é um programinha: ele segue ponteiros, repete, testa condições e faz as contas que um jogo usa para esconder seus números.

Por que os códigos comuns não bastam

GameShark, Action Replay e CodeBreaker foram feitos para cartuchos do começo dos anos 2000. São bons em “sempre escreva 99 aqui”, e é mais ou menos isso. Muitos jogos não guardam seus dados num lugar só:

  • Dados que se movem. Pokémon e muitos RPGs guardam a mochila, a equipe e o dinheiro atrás de um ponteiro, e o endereço muda a cada save ou até a cada vez que você abre um menu. Um código de endereço fixo funciona hoje e para de funcionar amanhã sem aviso.
  • Valores criptografados. FireRed e LeafGreen guardam seu dinheiro com XOR de uma chave diferente em cada save. Escrever 999999 direto dá um número aleatório; é preciso ler a chave antes.
  • Listas inteiras. Deixar cada item de uma mochila de 42 espaços em 99 exige 42 códigos separados, e eles se desalinham assim que você pega algo.
  • Condições. “Só enquanto eu seguro L+R”, “só em espaços vazios”, “só durante a batalha” ficam quase sempre fora de alcance.

Os códigos estendidos foram criados exatamente para esses casos.

O que eles fazem

  • Seguem ponteiros do mesmo jeito que o jogo, então um código continua funcionando em qualquer save.
  • Repetem sobre uma mochila, uma equipe ou uma caixa do PC, com repeat 42 … end.
  • Testam condições: comparam memória, testam bits, pulam espaços vazios e aceitam um else.
  • Reagem a botões: rodam só enquanto uma combinação de botões estiver pressionada, para “aperte L+R para curar”.
  • Calculam com oito registradores: soma, subtração, multiplicação, AND, OR, XOR e deslocamentos, o bastante para codificar um valor do jeito que o jogo espera.
  • Copiam um valor ou uma sequência inteira de espaços de outro lugar.
  • Alteram o jogo com linhas rom, para mudanças que só valores não conseguem (uma loja que cobra 1, atravessar paredes).
  • Oferecem opções. Uma linha option transforma um valor num menu suspenso na lista de cheats, e o jogador escolhe “×2 / ×5 / ×10” sem mexer no código.

Esquerda: o editor verifica o código enquanto você digita. Direita: códigos com opções ganham um menu suspenso na própria lista.

Um exemplo real

Dinheiro 999999 no FireRed (inglês v1.0). O dinheiro fica atrás de um ponteiro e criptografado com a chave do save, o que nenhum código comum consegue tratar:

hhcode 1
r0 = [0x03005008]        # bloco 1: dinheiro e itens
r1 = [0x0300500C]        # bloco 2: aqui fica a chave
r2 = [r1 + 0xF20]        # lê a chave
r2 = r2 ^ 999999         # codifica 999999 com ela
[r0 + 0x290].32 = r2     # escreve o dinheiro

Todo item da mochila em 99, pulando espaços vazios:

hhcode 1
r0 = [0x03005008]
r1 = [0x0300500C]
r2 = [r1 + 0xF20]
r2 = r2 ^ 99             # as quantidades também são criptografadas
r0 = r0 + 0x310          # a mochila: 42 espaços
repeat 42
  if [r0].16 != 0        # pula espaços vazios
    [r0 + 2].16 = r2
  end
  r0 = r0 + 4            # próximo espaço
end

Segure L+R para recuperar HP (endereço ilustrativo):

hhcode 1
if button L + R
  [0x02024330].16 = 999
end

Uma opção que o jogador pode mudar na lista de cheats:

hhcode 1
option Multiplier = 2 { 2 ×2; 5 ×5; 10 ×10 }
[0x02001000].8 = $Multiplier

Como usar

  1. Num jogo, abra o painel de cheats e vá para “Meus cheats”. Toque em +.
  2. Dê um nome e digite ou cole o código. A primeira linha deve ser hhcode (ou hhcode 1).
  3. O editor verifica cada linha enquanto você digita. Um erro aparece com o número da linha; um código válido mostra “sintaxe válida”.
  4. Não sabe o que um código faz, por exemplo um que alguém te mandou? Toque em “Explicar este código” e ele é descrito em linguagem simples.
  5. Não quer começar do zero? Abra “Modelos de código estendido”: travar um valor, cadeia de ponteiros, espaços consecutivos, copiar um valor, percorrer uma tabela, escrita condicional, ramo else, gatilho de botão, chave de bit e mais. Escolha um e mude o endereço e o valor.
  6. Toque em Adicionar e ligue. Como todo cheat, ele roda a cada quadro.

Muitas vezes você nem precisa escrever: as ferramentas de memória encontram um valor e escrevem um código estendido com ponteiro para você.

Feitos para serem seguros

  • Não travam o jogo. Cada passada é limitada a 200.000 instruções, então um laço escrito errado só para.
  • Larguras são tolerantes. Se um valor não cabe na largura que você escreveu, ela é ampliada e você é avisado, em vez de o valor ser cortado em silêncio.
  • Avisam sobre erros prováveis, como um endereço que parece um deslocamento de outro formato.
  • Valores são valores. Decimal e hexadecimal significam a mesma coisa, e você escreve o número, não a ordem dos bytes.

A biblioteca inteira fala essa língua

Os mais de 9.000 cheats da biblioteca embutida, para mais de 1.700 jogos, foram convertidos em códigos estendidos, e cada um foi conferido byte a byte com o original. Alguns jogos ganharam códigos estendidos escritos à mão que os formatos antigos não conseguiam expressar, como o dinheiro criptografado e a mochila cheia no FireRed. Códigos GameShark, Action Replay e CodeBreaker continuam funcionando exatamente como antes.
