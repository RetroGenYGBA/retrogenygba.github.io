Triches

La bibliothèque de triches intégrée fonctionne immédiatement. Vous pouvez aussi coller des codes trouvés ailleurs, ou écrire les vôtres.

Bibliothèque de triches intégrée

La bibliothèque couvre plus de 1 700 jeux avec plus de 9 000 triches. Ouvrez le panneau de triche dans un jeu : l'application trouve les triches de ce jeu grâce au code de jeu de la cartouche. Touchez Ajouter sur l'une d'elles et elle prend effet.

Quand l'application est en anglais, les noms des triches sont affichés en anglais.

Différentes versions d'un même jeu (1.0 et 1.1, par exemple) utilisent parfois des adresses différentes, donc un code de la bibliothèque peut ne pas marcher sur toutes. Si l'un ne marche pas, essayez un code d'une autre version ou trouvez le vôtre.

À gauche : « Base de données » liste les triches de ce jeu ; touchez Ajouter. À droite : « Mes triches », où chaque triche a son propre interrupteur. Touchez + pour coller un code.

Coller des triches

Collez un code dans le panneau de triche. Le format est détecté automatiquement et, une fois activé, le code est appliqué à chaque image. Pris en charge :

  • GameShark / Action Replay
  • CodeBreaker
  • Écritures directes en mémoire (VBA Raw et similaires)
  • Codes étendus RetroGenY (voir plus bas)

Utilisez # ou ! pour les commentaires et des titres [section] pour regrouper des lignes. Les lignes que l'application ne sait pas lire sont signalées au lieu d'être ignorées en silence.

Codes étendus RetroGenY

Notre propre format de triche suit les pointeurs, boucle, teste des conditions et réagit aux boutons, donc il fonctionne là où les codes ordinaires échouent : données qui bougent à chaque sauvegarde, argent chiffré, sacs entiers. L'éditeur vérifie pendant la saisie, explique n'importe quel code en langage clair et propose des modèles pour démarrer. Tout sur les codes étendus.

Créez les vôtres avec les outils mémoire

Vous ne trouvez pas la triche voulue ? Cherchez dans la mémoire du jeu depuis une fenêtre flottante, bloquez la valeur et laissez un point de surveillance la transformer en triche qui survit à une nouvelle sauvegarde. Vous pouvez même changer ce que fait le jeu, ou faire tourner chaque tirage aléatoire en votre faveur. Tout sur les outils mémoire.

Pendant le link

Toutes les triches sont suspendues pendant le link, et celles qui modifient le jeu sont d'abord annulées, pour que les deux jeux restent synchronisés. Elles reviennent quand vous débranchez.
