Codes étendus

Le format de triche propre à RetroGenY. Un code ordinaire écrit une valeur à une adresse. Un code étendu est un petit programme : il peut suivre des pointeurs, boucler, tester des conditions et faire les calculs qu'un jeu utilise pour cacher ses nombres.

Pourquoi les codes ordinaires ne suffisent pas

GameShark, Action Replay et CodeBreaker ont été conçus pour les cartouches du début des années 2000. Ils sont doués pour « écrire toujours 99 ici », et c'est à peu près tout. Beaucoup de jeux ne gardent pas leurs données au même endroit :

  • Des données qui bougent. Pokémon et beaucoup de RPG rangent le sac, l'équipe et l'argent derrière un pointeur, et l'adresse change à chaque sauvegarde, voire à chaque ouverture de menu. Un code à adresse fixe marche aujourd'hui et cesse de marcher demain sans prévenir.
  • Des valeurs chiffrées. Rouge Feu et Vert Feuille stockent votre argent avec un XOR par une clé différente pour chaque sauvegarde. Écrire directement 999999 donne un nombre aléatoire ; il faut d'abord lire la clé.
  • Des listes entières. Mettre à 99 chaque objet d'un sac de 42 emplacements demande 42 codes séparés, qui se décalent dès que vous ramassez quelque chose.
  • Des conditions. « Seulement quand je maintiens L+R », « seulement sur les emplacements vides », « seulement en combat » sont presque toujours hors de portée.

Les codes étendus ont été créés exactement pour ces cas.

Ce qu'ils savent faire

  • Suivre des pointeurs comme le fait le jeu, pour qu'un code continue de marcher dans n'importe quelle sauvegarde.
  • Boucler sur un sac, une équipe ou une boîte du PC, avec repeat 42 … end.
  • Tester des conditions : comparer la mémoire, tester des bits, sauter les emplacements vides, et ajouter un else.
  • Réagir aux boutons : ne s'exécuter que tant qu'une combinaison est maintenue, pour « appuyez sur L+R pour vous soigner ».
  • Calculer avec huit registres : addition, soustraction, multiplication, AND, OR, XOR et décalages, de quoi encoder une valeur comme le jeu l'attend.
  • Copier une valeur ou une série entière d'emplacements depuis ailleurs.
  • Modifier le jeu avec des lignes rom, pour des changements que les valeurs seules ne permettent pas (une boutique à 1, traverser les murs).
  • Proposer des choix. Une ligne option transforme une valeur en liste déroulante dans la liste des triches : le joueur choisit « ×2 / ×5 / ×10 » sans toucher au code.

À gauche : l'éditeur vérifie le code pendant la saisie. À droite : les codes avec options ont une liste déroulante directement dans la liste.

Un exemple réel

Argent 999999 dans Rouge Feu (anglais v1.0). L'argent est derrière un pointeur et chiffré avec la clé de la sauvegarde, ce qu'aucun code ordinaire ne sait gérer :

hhcode 1
r0 = [0x03005008]        # bloc 1 : argent et objets
r1 = [0x0300500C]        # bloc 2 : la clé est ici
r2 = [r1 + 0xF20]        # lit la clé
r2 = r2 ^ 999999         # chiffre 999999 avec elle
[r0 + 0x290].32 = r2     # écrit l'argent

Chaque objet du sac à 99, en sautant les emplacements vides :

hhcode 1
r0 = [0x03005008]
r1 = [0x0300500C]
r2 = [r1 + 0xF20]
r2 = r2 ^ 99             # les quantités sont chiffrées aussi
r0 = r0 + 0x310          # le sac : 42 emplacements
repeat 42
  if [r0].16 != 0        # saute les cases vides
    [r0 + 2].16 = r2
  end
  r0 = r0 + 4            # case suivante
end

Maintenez L+R pour remplir les PV (adresse donnée à titre d'exemple) :

hhcode 1
if button L + R
  [0x02024330].16 = 999
end

Un choix que le joueur peut changer depuis la liste des triches :

hhcode 1
option Multiplier = 2 { 2 ×2; 5 ×5; 10 ×10 }
[0x02001000].8 = $Multiplier

Comment les utiliser

  1. En jeu, ouvrez le panneau de triche et allez dans « Mes triches ». Touchez +.
  2. Donnez-lui un nom, puis tapez ou collez le code. La première ligne doit être hhcode (ou hhcode 1).
  3. L'éditeur vérifie chaque ligne pendant la saisie. Une erreur s'affiche avec son numéro de ligne ; un code valide indique « syntaxe valide ».
  4. Vous ne savez pas ce que fait un code, par exemple un qu'on vous a envoyé ? Touchez « Expliquer ce code » et il vous est décrit en langage clair.
  5. Pas envie de partir de zéro ? Ouvrez « Modèles de code étendu » : bloquer une valeur, chaîne de pointeurs, emplacements consécutifs, copier une valeur, parcourir une table, écriture conditionnelle, branche else, déclencheur par bouton, interrupteur de bit et plus. Choisissez-en un et changez l'adresse et la valeur.
  6. Touchez Ajouter et activez-le. Comme toute triche, il s'exécute à chaque image.

Souvent, vous n'avez même pas besoin d'en écrire un : les outils mémoire trouvent une valeur et écrivent pour vous un code étendu par pointeur.

Conçus pour être sûrs

  • Ils ne peuvent pas bloquer le jeu. Chaque passe est plafonnée à 200 000 instructions : une boucle mal écrite s'arrête simplement.
  • Les largeurs sont tolérantes. Si une valeur ne tient pas dans la largeur écrite, celle-ci est élargie et vous êtes prévenu, au lieu de couper la valeur en silence.
  • Ils signalent les erreurs probables, comme une adresse qui ressemble à un décalage d'un autre format.
  • Une valeur est une valeur. Décimal et hexadécimal veulent dire la même chose, et vous écrivez le nombre, pas son ordre d'octets.

Toute la bibliothèque parle cette langue

Les plus de 9 000 triches de la bibliothèque intégrée, pour plus de 1 700 jeux, ont été converties en codes étendus, et chacune a été vérifiée octet par octet par rapport à l'original. Certains jeux ont reçu des codes étendus écrits à la main que les anciens formats ne pouvaient pas exprimer, comme l'argent chiffré et le sac complet dans Rouge Feu. Les codes GameShark, Action Replay et CodeBreaker fonctionnent toujours exactement comme avant.
