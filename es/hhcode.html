Códigos extendidos

El formato de trucos propio de RetroGenY. Un código normal escribe un valor en una dirección. Un código extendido es un programa corto: puede seguir punteros, repetir, comprobar condiciones y hacer la aritmética que usa un juego para esconder sus números.

Por qué los códigos normales se quedan cortos

GameShark, Action Replay y CodeBreaker se diseñaron para cartuchos de principios de los 2000. Son buenos en «escribe siempre 99 aquí», y poco más. Muchos juegos no guardan sus datos en un solo sitio:

  • Datos que se mueven. Pokémon y muchos RPG guardan la mochila, el equipo y el dinero detrás de un puntero, y la dirección cambia con cada partida guardada o incluso cada vez que abres un menú. Un código de dirección fija funciona hoy y deja de funcionar mañana sin avisar.
  • Valores cifrados. Rojo Fuego y Verde Hoja guardan tu dinero aplicando XOR con una clave distinta en cada partida. Escribir 999999 directamente te da un número aleatorio; primero hay que leer la clave.
  • Listas enteras. Poner a 99 cada objeto de una mochila de 42 huecos requiere 42 códigos distintos, y se descuadran en cuanto recoges algo.
  • Condiciones. «Solo mientras pulso L+R», «solo en huecos vacíos», «solo durante el combate» están casi siempre fuera de alcance.

Los códigos extendidos se crearon justo para estos casos.

Qué pueden hacer

  • Seguir punteros igual que lo hace el juego, así que un código sigue funcionando en cualquier partida.
  • Repetir sobre una mochila, un equipo o una caja del PC, con repeat 42 … end.
  • Comprobar condiciones: comparar memoria, probar bits, saltarse huecos vacíos y añadir un else.
  • Reaccionar a los botones: ejecutarse solo mientras se mantiene una combinación, para «pulsa L+R para curar».
  • Calcular con ocho registros: suma, resta, multiplicación, AND, OR, XOR y desplazamientos, suficiente para codificar un valor como espera el juego.
  • Copiar un valor o una serie entera de huecos desde otro sitio.
  • Parchear el juego con líneas rom, para cambios que los valores solos no consiguen (una tienda que cobra 1, atravesar paredes).
  • Ofrecer opciones. Una línea option convierte un valor en un desplegable de la lista de trucos, para que el jugador elija «×2 / ×5 / ×10» sin tocar el código.

Izquierda: el editor comprueba el código mientras escribes. Derecha: los códigos con opciones tienen un desplegable en la propia lista.

Un ejemplo real

Dinero 999999 en Rojo Fuego (inglés v1.0). El dinero está detrás de un puntero y cifrado con la clave de la partida, algo que ningún código normal puede manejar:

hhcode 1
r0 = [0x03005008]        # bloque 1: dinero y objetos
r1 = [0x0300500C]        # bloque 2: aquí está la clave
r2 = [r1 + 0xF20]        # lee la clave
r2 = r2 ^ 999999         # cifra 999999 con ella
[r0 + 0x290].32 = r2     # escribe el dinero

Todos los objetos de la mochila a 99, saltando huecos vacíos:

hhcode 1
r0 = [0x03005008]
r1 = [0x0300500C]
r2 = [r1 + 0xF20]
r2 = r2 ^ 99             # las cantidades también van cifradas
r0 = r0 + 0x310          # la mochila: 42 huecos
repeat 42
  if [r0].16 != 0        # salta huecos vacíos
    [r0 + 2].16 = r2
  end
  r0 = r0 + 4            # siguiente hueco
end

Mantén L+R para recuperar PS (dirección de ejemplo):

hhcode 1
if button L + R
  [0x02024330].16 = 999
end

Una opción que el jugador puede cambiar desde la lista de trucos:

hhcode 1
option Multiplier = 2 { 2 ×2; 5 ×5; 10 ×10 }
[0x02001000].8 = $Multiplier

Cómo usarlos

  1. En un juego, abre el panel de trucos y ve a «Mis trucos». Toca +.
  2. Ponle un nombre y escribe o pega el código. La primera línea debe ser hhcode (o hhcode 1).
  3. El editor comprueba cada línea mientras escribes. Un error se muestra con su número de línea; un código válido indica «sintaxis válida».
  4. ¿No sabes qué hace un código, por ejemplo uno que te enviaron? Toca «Explicar este código» y te lo describe en lenguaje sencillo.
  5. ¿No quieres empezar de cero? Abre «Plantillas de código extendido»: fijar un valor, cadena de punteros, huecos consecutivos, copiar un valor, recorrer una tabla, escritura condicional, rama else, activación con botones, interruptor de bit y más. Elige una y cambia la dirección y el valor.
  6. Toca Añadir y actívalo. Como todos los trucos, se ejecuta en cada fotograma.

Muchas veces ni siquiera tienes que escribirlo: las herramientas de memoria encuentran un valor y te escriben un código extendido con punteros.

Pensados para ser seguros

  • No pueden congelar el juego. Cada pasada está limitada a 200.000 instrucciones, así que un bucle mal escrito simplemente se detiene.
  • Los anchos son flexibles. Si un valor no cabe en el ancho que escribiste, se amplía y se te avisa, en vez de recortarse en silencio.
  • Avisan de errores probables, como una dirección que parece un desplazamiento de otro formato.
  • Los valores son valores. Decimal y hexadecimal significan lo mismo, y escribes el número, no su orden de bytes.

Toda la biblioteca lo habla

Los más de 9.000 trucos de la biblioteca integrada para más de 1.700 juegos se han convertido a códigos extendidos, y cada uno se comprobó byte a byte con el original. Algunos juegos recibieron códigos extendidos escritos a mano que los formatos antiguos no podían expresar, como el dinero cifrado y la mochila completa de Rojo Fuego. Los códigos GameShark, Action Replay y CodeBreaker siguen funcionando exactamente igual que antes.
